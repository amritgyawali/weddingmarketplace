# 19. Troubleshooting

Problems people have actually hit on this project, and their fixes. Add new ones at the end with a date.

| Symptom | Cause | Fix |
|---|---|---|
| `tsc` rejects `router.push('/onboarding')` after adding `src/app/onboarding/index.tsx`; types say `/onboarding/index` | Metro's incremental typed-routes generator wrote a stale `.expo/types/router.d.ts` (seen 30 Sep 2026, SDK 57) | Finish edits, delete `.expo/types/router.d.ts`, restart `npx expo start --clear`, re-run tsc. Don't cast hrefs. |
| A new route isn't typed at all | Typed routes are generated by `expo start` | Start `npx expo start` once, then run tsc |
| In a worktree, the web app shows old screens while components are new | Metro's shared transform cache served another worktree's route context | Start Metro with `--clear` the first time in each worktree |
| Edits never reach the bundle | `CI=1` turns off Metro's file watcher | Don't set `CI=1` for interactive runs |
| `npm ci` fails in CI after a lockfile change made on Windows | Windows npm drops Linux-only optional entries (`@emnapi`) | Don't regenerate `package-lock.json` on Windows; restore it from `main` (R-OPS-2) |
| A second Metro crashes the machine | Low RAM (~8 GB, often < 1 GB free) | Reuse the running Metro (check ports 8081/8082) |
| Disk full mid-session | C: drive hit 0 bytes free (1 Oct 2026) | Check free space before `expo start` or `expo export`; clear caches |
| Node string-replace scripts don't match | Files are checked out with CRLF (`core.autocrlf`) | Match `\r\n`, or use an editor |
| Screen re-renders forever | A zustand selector returns a new array/object each time | Select the raw collection; filter in render (R-FE-4) |
| Taps dropped on Android right after an action | Synchronous persistence or animated press styles | Keep `lazyStorage`; keep `PressableScale` a plain `Pressable` |
| Demo shows a reply after Reset demo data | Untracked demo timers (auto-quote 4 s, phone confirmation 3.5 s) | Known gap ([05 §7](05-state-and-data.md#7-simulated-third-parties)) |
| User data wiped after an update | A persisted store was `setState` at module load, or a migration replaced data | Never set persisted state at load; migrations must be additive (R-STATE-6) |
| `<button>` inside `<button>` warning on web | Nested pressables | Make the tappable area and buttons siblings (R-FE-6) |
| Push works in a build but not in Expo Go | Remote push isn't available in Expo Go (Android, SDK 53+) | Expected; use a development build |
| `git push` returns 403 | Git cached credentials for a different GitHub account (seen 2 Oct 2026) | Sign in again as the repository owner's account |
| Dates show one day early | `new Date('yyyy-mm-dd')` parsed as UTC | Use `fromISODate` / `toISODate` ([11 §2](11-i18n-dates-money.md#2-dates)) |
| BS dates wrong or missing after April 2034 | The BS month table ends at BS 2090 | Extend `TABLE` in `src/utils/bs.ts` ([11 §2](11-i18n-dates-money.md#2-dates)) |
| `docs:check` fails in a pull request | Code changed without regenerating the reference | `npm run docs:generate` and commit `docs/reference/` |
